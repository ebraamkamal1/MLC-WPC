# MLC — Modern Lines Company for Industry

Static bilingual company-profile website built from the supplied MLC WPC Doors catalog.

## Structure
- `index.html` — page structure and editable content blocks
- `css/styles.css` — all visual styling and responsive rules
- `js/app.js` — Arabic/English switch + catalog data + catalog modal
- `assets/logo.png` — extracted from the supplied catalog
- `assets/facility.jpg` — company/factory visual from the catalog
- `assets/catalog/` — selected catalog pages used as visual references

## Run
Open `index.html` directly, or serve the folder with any static server.

## Easy editing
- Door names/images: edit `catalogItems` in `js/app.js`.
- Arabic/English text: edit `copy` in `js/app.js`.
- Colors: edit the variables at the top of `css/styles.css`.
- Main sections: edit `index.html`.
